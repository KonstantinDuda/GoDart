# Flame Tic-Tac-Toe (Хрестики-Нулики)

Сучасна, кросплатформена ігрова реалізація класичної гри **Хрестики-Нулики**, побудована на базі потужного 2D-рушія **Flame** та архітектурного патерну **BLoC** для керування станом. 

Проект демонструє ідеальну синергію між ігровим циклом (Game Loop) та декларативним підходом Flutter.

---

## 🚀 Особливості проекту

* **Повний Game Loop на Flame**: Малювання сітки, анімованих хрестиків та нуликів реалізовано на низькому рівні за допомогою `Canvas` та методів `render`/`update`.
* **Архітектура Flame + BLoC**: Стан гри, черговість ходів, вибір режимів та бізнес-логіка повністю відокремлені від візуальної частини й контролюються через `GameBloc`. Компоненти Flame синхронізовані через `FlameBlocListenable`.
* **Плавні Canvas-анімації**: Фігурки не просто з'являються на екрані, а динамічно малюються:
    * **Хрестик (`X`)**: Послідовне викреслювання ліній вектор за вектором.
    * **Нулик (`O`)**: Плавне розгортання дуги (`drawArc`) за годинниковой стрілкою на основі дельти часу (`dt`).
* **Адаптивний UI (Responsive Layout)**: 
    * Екран чітко поділений на дві зони: бокове меню (30% ширини) та ігрову область (70% ширини).
    * Компоненти динамічно перераховують свої розміри та відступи через `onGameResize` з використанням безпечного ключового слова `this.size` для запобігання затінення змінних.
* **Гібридний інтерфейс (Flame Overlays)**: Модальне вікно (запит на нову онлайн-гру) реалізований як нативні Flutter-віджети, що накладаються поверх ігрового рушія, забезпечуючи чистий Material дизайн.

## 📐 Архітектура компонентів

Проект побудований на базі ієрархічного дерева компонентів всередині `FlameBlocProvider`:

* `RootPage (FlameGame)` — Головний ігровий рушій, задає колір фону.
* `MenuComponent` — Контейнер бокової панелі меню. Керує розмірами та позиціонуванням дочірніх елементів.
    * `MenuButtonComponent` — Кнопки вибору режимів гри. Використовують `onMount` та `addPostFrameCallback` для безпечної синхронізації зі стартовим станом Блоку.
* `BoardComponent` — Ігрове поле 3х3. Обробляє тапи користувача, вираховує індекси клітинок за формулою `row * 3 + col` та рендерить анімовані фігурки.
* `StatusTextComponent` — Текст над полем, що показує поточний хід або переможця.
* `NewGameButtonComponent` — Кнопка скидання раунду, адаптивно прив'язана до нижньої межі ігрового поля.

Вся гра реалізована у сучасному Dark-стилі з використанням інтуїтивно зрозумілого формату `Color.fromARGB`:

* **Фон гри:** Deep Dark Blue `Color.fromARGB(255, 26, 28, 41)`
* **Панель меню:** Darker Blue `Color.fromARGB(255, 20, 21, 30)`
* **Сітка поля:** Soldier Green `Color.fromARGB(255, 96, 97, 63)`
* **Хрестики (X):** Coral Red `Color.fromARGB(255, 235, 94, 85)`
* **Нулики (O):** Bright Sky Blue `Color.fromARGB(255, 84, 172, 230)`
* **Активна кнопка:** Soldier Green `Color.fromARGB(255, 33, 150, 243)`

## 🖥️ Серверна частина (Backend на Go)

Логіка мережевої гри (режим `Грати онлайн`) обслуговується високопродуктивним мікросервером, написаним на **Go (Golang)**. Сервер виступає в ролі координатора ігрових сесій та забезпечує миттєвий обмін даними між клієнтами.

* **Реалтайм комунікація**: Взаємодія побудована на базі протоколу **WebSockets** (використовується пакет `gorilla/websocket`), що мінімізує затримки під час передачі ходів.
* **Архітектура сесій**: Сервер обробляє підключення, створює унікальні ігрові кімнати (роуми), відстежує стан підключених гравців та синхронізує `gameplayState` між ними.
* **Подієва модель**: Кожен крок користувача (натискання на клітинку, запит на нову гру) серіалізується в JSON та миттєво транслюється супернику, де `GameBloc` на боці Flutter приймає рішення про оновлення стану Flame.

## 🏁 Як запустити проект

Щоб протестувати мережевий режим гри, вам знадобиться запустити як локальний сервер, так і клієнтський додаток Flutter.

### 1. Як запустити клієнт (Flutter)

1. Переконайтеся, що у вас встановлено Flutter SDK (версії 3.x або вище).
2. Клонуйте репозиторій:
   git clone https://github.com/KonstantinDuda/GoDart.git
3. Перейдіть у директорію клієнта
    cd game_client
4. Запустіть ігровий клієнт:
    * На підключенному пристрої (емуляторі/смартфоні):
    ```bash 
   flutter run```
    * На лінукс:
   ```bash 
   flutter run -d linux```
   * Або в браузері Chrome:
   ```bash
   flutter run -d chrome```

Для тестування онлайн-режиму запустіть два окремі екземпляри додатка (наприклад, у Chrome та на емуляторі), запустіть сервер, оберіть режим "Грати онлайн" та протестуйте систему надсилання запитів і синхронізацію ходів.

### 2. Запуск сервера (Go)
Переконайтеся, що у вас встановлено Go (версії 1.18+).

1. Відкрийте термінал та перейдіть у папку з сервером:
   ```bash
   cd server
2. Завантажте необхідні модулі:
   ```bash 
   go mod tidy
3. Запустіть сервер:
   ```bash
   go run .
